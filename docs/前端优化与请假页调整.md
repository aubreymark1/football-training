# 前端优化与“我的请假”页调整

## 背景

前一轮把模板展开、抽出 `csrf_field()`，但子页面样式仍各写一套颜色，首页首屏被赛程卡和看板占满，请假表单又埋在账号页中部。这一轮同时推进两个方向：

- 工程方向：模板和样式的公共部分收口，减少重复和死代码。
- 体验方向：首页先看到“去提交”，请假有自己的页面和多个入口。

## 逐项改动

### 模板与样式

- 所有样式表链接都移进 `base.html` 的 `{% block head %}`，不再写在 `<body>` 里等渲染到才下载。
- 每个页面都有 `<title>`，格式统一为“页面名 · LINGNAN UNITED”。
- 子页面样式表改为一行一条规则（`home.css`、`matches.css`、`moments.css`、`plans.css`、`lottery.css`、`training-leave.css`、`avatar.css`、`site-updates.css`），便于阅读和 diff。
- 颜色收口到 `style.css` 的 `:root`：新增 `--dark`、`--dark-soft`、`--pitch-mid` 和赛程用的 `--warm-*`；`matches.css`、`moments.css`、`lottery.css`、`plans.css`、`training-leave.css`、`avatar.css` 里重复的十六进制值改用变量，各文件自己的 `--match-*`、`--case-*`、`--plan-*` 改为指向全局变量。
- `league.css` 改名为 `home.css`，只保留首页用的样式。
- 删除已停用功能的样式：球员评分、比赛右侧标签页、计划编辑器的 AI 面板、动态页的小标签、`.training-reason` 等。
- 静态内联样式改为工具类（`.mt-12`、`.mt-16`、`.form-flat`、`.avatar-link`、`.tap`），只保留图表偏移、进度条宽度这类必须动态计算的 `style`。
- 头像的默认图由后端 `avatar_image` 直接返回或按球员是否在职判断，模板里不再用 `onerror` 兜底。
- 训练记录状态文案统一由 `status_label()` 提供，首页、我的训练和管理审核不再各写一份映射。
- 比赛中心的返回链接、按钮、表单改用全局的 `.back`、`.smallbtn`、`.outline`、`.textbtn`、`.stack`。
- 移除已停用的训练助手前端：`chat-ui/`、`static/chat/`、`templates/assistant.html`、`/assistant` 页面路由和只服务它的样式段。

### 体验

- 首页顶部“下一场比赛”改成两行高的横条：日期、对阵、比赛中心和请假各占一个可点区域；手机上首次进入就能看到必做任务的“去提交”（375×667 下按钮底部约 529px，320×640 下约 592px）。
- 手机上的本周训练看板适当收紧内边距和字号。
- 新增独立请假页 `/leave`：训练、比赛分组折叠，`训练请假` 默认展开；空状态、记录和按钮文案沿用原有规则。
- 账号页顶部保留一张“我的请假”入口卡，显示训练/比赛有效请假次数；账号页只留设置项。
- 请假入口只在账号页顶部那张“我的请假”卡片；首页赛程条、比赛详情、训练详情曾在第一版加上“请假 / 去请假”按钮，2026-11-23 按反馈移除，这三处只保留“已请假”的状态文字，并提示到账号设置里修改。带 `#training-2`、`#match-3` 进入请假页时仍会自动展开并定位到对应场次（`static/leave.js`），链接可从外部或历史记录进入。
- 底部导航统一中文：“训练 / 动态 / 比赛中心 / 球队 / 积分”；管理员入口从底栏移到页眉的“管理”，底栏固定 5 项。
- 动态和赛后反思的点赞、评论改为 `fetch` 局部更新（`static/interactions.js`），失败时自动退回整页提交；点赞后不再跳回页顶。
- 赛后反思图片带上 `width`/`height`（上传时记录尺寸），列表用 `?thumb=1` 缩略图，点击用站内放大层查看。
- 头像上传改用与训练记录一致的虚线选择框，选图后显示缩略图、文件名和体积。
- 点击区域：`比赛中心`、`全部记录`、评论/隐藏/删除、折叠标题、`查看截图` 等都撑到 36px 以上。

## 数据与兼容

- `match_reflections` 新增 `image_w`、`image_h` 两列，启动时自动补齐；旧记录的图片没有尺寸，模板会省略这两个属性，不影响显示。
- 请假接口地址不变（`/training-sessions/<id>/leave`、`/account/match-leave/<id>`），只把成功后的跳转目标改到 `/leave`。
- 账号页不再计算完整请假列表，只查询两项计数，减少查询量。
- 训练/比赛请假表结构、72 小时规则和出勤规则均未改动。
